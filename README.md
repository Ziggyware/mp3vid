# mp3vid

A small music-video studio that turns an MP3 into a vertical, sound-reactive short. It ships with an original instrumental demo, so you can try the workflow before adding your own track.

## Run locally

Requires Node.js 20.19+ (or Node 22+) and npm. The FFmpeg binary used for MP4 conversion is installed as an npm dependency on supported platforms.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production build:

```bash
npm run build
npm start
```

The server binds to `0.0.0.0:3000` by default; set `PORT` to change it. If the bundled FFmpeg binary is not available for your platform, set `FFMPEG_PATH` to an executable FFmpeg build with H.264 (`libx264`) and AAC encoders.

## Whisper transcription

Whisper is optional: you can always type captions manually. To enable automatic transcription, either enter an OpenAI API key in the app when prompted, or copy `.env.example` to `.env` and set `OPENAI_API_KEY`. An environment-configured key enables automatic transcription when a new track is uploaded. The server needs outbound access to `api.openai.com`; normal OpenAI usage charges may apply. The app uses `whisper-1` with word timestamps and groups those words into timed captions. Review the results for accuracy.

A key entered in the app remains in the current browser session and is passed to the server only for transcription; the server does not save it. Use HTTPS when hosting the app remotely. When transcription is requested, the MP3 is sent to OpenAI. Without a configured key, no audio is sent to OpenAI. MP3s must be at least one second long and are limited to 25 MB.

## How it works

1. **Track:** Decode the MP3 and build its waveform in the browser. The demo is generated by `scripts/generate-demo.py` and is not a commercial song.
2. **Hook:** Score clip windows using audio energy and dynamics, with a small bonus for repeated word pairs when Whisper timings are available. This is a heuristic, not a prediction of a song's popularity. Drag the selection or use the arrow keys to choose a different moment.
3. **Captions:** Use Whisper's timed words or type your own. Separate manual captions with blank lines to distribute them evenly across the selected clip. Editing a Whisper transcript switches to manual, evenly spaced timing.
4. **Visualize:** A WebGL shader animates the artwork in response to the audio, with three selectable looks. Browsers without WebGL fall back to a static background with the animated spectrum and captions.
5. **Export:** The browser records the preview and selected audio in real time. The server temporarily receives that recording and uses FFmpeg to make a 1080 × 1920, 30 fps H.264/AAC MP4. The internal canvas is 540 × 960 and is upscaled for export. Temporary conversion files are removed after the response or an error. If conversion fails, the app offers the original browser recording (usually WebM) instead.

Keep the tab open during recording. A current Chrome or Edge browser is recommended because exporting requires `MediaRecorder`, canvas capture, and Web Audio support. The resulting file is ready to upload to TikTok, Instagram Reels, or YouTube Shorts; the app does not publish to those services directly. Only upload and share audio you have rights to use.

Run the audio, caption, and server/export tests with `npm test`.
