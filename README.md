# mp3vid

A small music-video studio that turns an MP3 into a vertical, sound-reactive short. It ships with an original instrumental demo, so you can try the workflow before adding your own track.

## Run locally

Requires Node.js 20.19+ (or Node 22+) and npm. The FFmpeg binary used for MP4 conversion is installed as an npm dependency on supported platforms.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production build:

```bash
npm run build
npm start
```

The server binds to `0.0.0.0:3000` by default; set `PORT` to change it. If the bundled FFmpeg binary is not available for your platform, set `FFMPEG_PATH` to an executable FFmpeg build with H.264 (`libx264`) and AAC encoders.

## No API keys

mp3vid does not use OpenAI or any other paid or keyed service. Your track is decoded and analyzed entirely in your browser: the waveform, loudness, beat grid, silence, and section changes are all computed locally. Captions are typed by you, so there is nothing to configure and no audio is sent to a third party.

## How it works

1. **Track:** Decode the MP3 in the browser and build a zoomable timeline. It shows the waveform at full resolution, a ruler, the beat grid and bar numbers (when the tempo is clear), where audio starts and ends, loudness lifts and drops, and a hook-score curve. The demo is generated by `scripts/generate-demo.py` and is not a commercial song.
2. **Hook:** Score clip windows using audio energy and dynamics. This is a heuristic, not a prediction of a song's popularity. Drag the lime clip on the map, click a ▲ lift or ▼ drop marker to jump to it, or use the arrow keys. Snapping pulls the clip edges onto landmarks; Ctrl + scroll zooms, and Shift + scroll pans.
3. **Captions:** Type your own captions. Separate them with blank lines to distribute them evenly across the selected clip.
4. **Visualize:** Six artworks cycle through the clip, changing on beat-aligned boundaries (every two bars when the tempo is known). Each change uses one of six WebGL transitions: liquid dissolve, glitch slices, zoom burst, mosaic, diagonal wipe, or iris. Artwork drifts slowly, punches on the bass, and flashes on the downbeat. Three selectable looks adjust the colors. Browsers without WebGL fall back to a cross-fade with the animated spectrum and captions.
5. **Export:** The browser records the preview and selected audio in real time. The server temporarily receives that recording and uses FFmpeg to make a 1080 × 1920, 30 fps H.264/AAC MP4. The internal canvas is 540 × 960 and is upscaled for export. Temporary conversion files are removed after the response or an error. If conversion fails, the app offers the original browser recording (usually WebM) instead.

Keep the tab open during recording. A current Chrome or Edge browser is recommended because exporting requires `MediaRecorder`, canvas capture, and Web Audio support. The resulting file is ready to upload to TikTok, Instagram Reels, or YouTube Shorts; the app does not publish to those services directly. Only upload and share audio you have rights to use.

Run the audio, caption, and server/export tests with `npm test`.
